A Generating Algorithm for the Escaping Parameter Sets of the Exponential and Cosine Families and Its Accuracy

September, 2025

This paper is currently under review, so is not available here.

We present a plotting algorithm for the escaping parameter sets of the exponential family and cosine family. We prove that the generated images are correct on any given closed square region in the arameter plane, except for a few pixels. The same is true for the Julia set of exponential family, using the modified algorithm. Such algorithms possess greater advantages and generality in analyzing the correctness and accuracy of the generated images.

This work is in collaboration with Xiaojie Huang and Yuntong Li.

Branden-Krasikov-Shapiro Type Theorem for Linear Difference Operator

December, 2024

This paper is currently under review, so is not available here.

We give a complete characterisation of the entire function f which both f and its general linear difference Lf omit zero. It can be seen as a difference version of the Frank-Hellerstein theorem, which can be regarded as a dual version of (localized) Hermite-Poulain theorem in some sense. With this characterisation in hand, we establish a version of Brändén-Krasikov-Shapiro theorem for linear difference operator preserving ΠE(∅). Our method can be extended partially to a meromorphic function with finitely many zeros and poles.

In collaboration with Xiao Yao and Yiming Zhang.

Long Memory in Stock Return Volatility in Chinese Stock Market

April, 2024

This is my undergraduation thesis, under the supervision of Professor Mingtao Wang.

This paper investigates long memory in the volatility of daily squared returns for Chinese stocks using GPH estimation. Rolling estimation reveals that 98.92% of stocks show significant long memory. A cross-sectional analysis finds a negative correlation between long memory and future excess returns, suggesting that higher volatility predictability leads to lower risk premiums. The findings are robust across industry sectors.

All analyses presented in this paper are implemented through self-developed Python scripts.
